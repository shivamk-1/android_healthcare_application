# Android Healthcare Application

An Android application designed to provide healthcare-related features and services through a mobile platform.

## Technologies Used
- Java
- Android Studio
- XML

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/shivamk-1/android_healthcare_application.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle to sync and download the required dependencies.
5. Connect an Android device or start an emulator.
6. Click **Run** to launch the application.
